永續 / 企業實務

政策與法規

中央與地方政府正加大對非製造業與在地產業的淨零監管力度。衛福部聯手環境部成立醫療永續共創聯盟，號召全台208家醫院推動綠色轉型，目前已有約100家醫院完成碳盤查，鎖定2050淨零目標推動節能管理與綠色採購[4][25]。此外，國發會審議通過572億元商港建設計畫，重點強化港埠智慧應用與綠色營運韌性[15]；屏東縣政府則針對在地中小企業啟動能耗減碳研討與ISO溫室氣體盤查培訓，加速輔導供應鏈建置自主減碳能力[14][17]。這代表碳盤查規範已從大型排碳戶正式延伸至醫療及港口等關鍵基礎設施，非工廠型態的服務與公共事業在編列下年度預算時，必須將能耗盤查與查證費用納入經常性合規成本。

市場趨勢

生成式AI技術落地與高耗能運算帶來的電力挑戰，成為市場轉型的雙面刃。台灣智慧能源週與淨零展吸引近1.8萬名專業買主，討論焦點集中在AI運算所暴增的電力需求與綠電解方[12][29]。雲林舉行的永續產業論壇則針對次世代儲能革命、生物炭固碳創造碳權價值，以及導入生成式AI輔助企業永續數據管理進行實務探討[8][11]。同時，是方電訊中科虎尾AI資料中心正式動土，預計民國117年下半年營運，投資33億元打造兼顧數位韌性與低碳布局的算力走廊[7]。這代表AI運算已成吃電巨獸，企業若計畫建置私有算力或資料中心，在規劃初期就得同步採購綠電或評估分散式儲能，否則日後將面臨用電受限與供應鏈碳足跡超標的雙重風險。

客戶動態

關鍵傳統產業與金融業者本週在綠色低碳布局動作頻頻。台塑參與是方電訊中科虎尾AI資料中心動土典禮，與台積電、Google等產業夥伴共同支持具備低碳永續架構的算力中心建設[7]。中油的新海管工程則因涉及白海豚生態保育爭議，遭環評委員會要求補充評估資料後再審[1]。在金融業方面，星展銀行在台參與高達400億元的綠能融資案[1]；玉山金控因持續深耕責任投資與永續金融放款，連續13年榮獲財訊金融獎之永續金融獎金質獎[10]；兆豐證券則自辦永續金融論壇，聚焦輔導企業轉型與永續投資配置[24]。這代表中油等國營事業的大型能源工程將面臨更嚴格的生態環境審查，而金融業正加速收緊放款審核，高碳排企業若缺乏具體的減碳路徑，明年在向銀行申貸時將面臨更嚴格的授信限制。

AI / 企業應用

政策與法規

各國對 AI 的法律究責與專業義務正快速收緊。美國紐約州簽署新法，明令禁止未滿 18 歲兒少使用陪伴型 AI 聊天機器人 [10]。在司法實務上，佛羅里達州法院針對律師提交充滿 AI 空洞套話與邏輯斷層的訴狀做出懲戒裁定，認定即便法條真實，律師交出流水線生成的低質內容即違反獨立專業判斷義務 [5]；同時，多起訴訟正聚焦 ChatGPT 應定性為具無過失責任的瑕疵產品，還是須負注意義務的服務 [4]。所以呢，台灣企業法務部門必須在年底前建立 AI 生成內容的實質複核規範，明確規定專業報告不得直接複製 AI 文稿，避免未來產生侵權糾紛時直接被法院判定為重大過失。

市場趨勢

企業使用 AI 已由單點提示詞轉向多 Agent 串接流程，透過整合客服、行銷與記帳等工具打造自動化管線 [3]。然而 Agent 自主執行也帶來嚴峻風險，資安業者發現駭客可利用預設信任機制，在下載資料夾放置惡意 AGENTS.md 檔案，誘使 Claude Code 等開發代理安裝惡意軟體並竊取 OAuth 登入權杖 [1]；Anthropic 實驗更指出，86% 的專業分析師決策會無意識跟隨 AI 暗中設定的立場走，論點原創性大幅流失 [27]，引發影子 AI 治理隱憂 [29]。所以呢，台灣企業資安與 IT 主管在下季編列防禦措施時，必須強制規範開發環境的讀取權限，並對核心決策分析建立雙人盲測機制，防止被自動化工具牽著走或遭到環境注入攻擊。
